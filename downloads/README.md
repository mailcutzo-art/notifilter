# Notifilter Android test build

[Download Notifilter.apk](https://github.com/mailcutzo-art/notifilter/raw/refs/heads/main/downloads/Notifilter.apk)

This APK is a development-signed release build for local Android testing (Android 8.0/API 26 or newer). It is not a production release and has not been tested on a physical device.

Implemented: High / Normal / Low notification priorities, native monitoring and conservative rule-based classification, app rules, metadata history, privacy controls and a test lab. Original notifications remain unchanged. Trained AI inference and Intelligent Quiet Mode are not implemented. The release manifest has no Internet permission.

Enable installation from the browser when Android requests it. Open the app, review the notification-access explanation, grant access in Android settings, and enable monitoring. Default monitoring processes notifications only while the device is non-interactive; always-on classification can be enabled in the test lab.
